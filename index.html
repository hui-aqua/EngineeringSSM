提交新软件或程序库

填写后可在本机目录中预览，并导出 JSON 或创建 GitHub Issue 供审核。

GitHub Pages 是静态托管，不能直接把表单提交写入仓库。此原型支持本机保存与 JSON 导出；配置仓库后，可以生成 GitHub Issue 提交建议。经审核后再将记录合并到软件数据文件。

本机目录使用浏览器 localStorage；只存在于当前浏览器，不会自动同步给其他用户或设备。

GitHub 提交设置

无需在网页中保存 Personal Access Token。建议通过 Issue 审核，避免把密钥放在公开的静态网页中。

推荐的持久化工作流

  1. 用户通过此页面填写软件信息。
  2. 页面生成预填内容的 GitHub Issue，不需要网页保存访问令牌。
  3. 维护者审核软件功能、许可证和来源。
  4. 确认后更新仓库中的 data/software.json，再由 GitHub Pages 自动部署。
